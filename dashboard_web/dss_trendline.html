Pengujian Model Inferensi Langsung & Peta Atensi Transformer
Modal API Aktif (200 OK)

Antarmuka ini menguji masukan kalimat opini masyarakat secara seketika menggunakan model produksi IndoBERT Base + R-Drop (Akurasi Acuan Manusia 0,7882 / Macro F1 0,7700) yang terhubung ke cloud serverless Modal. Sistem menyajikan hasil klasifikasi tiga kelas, distribusi probabilitas softmax, serta visualisasi peta atensi transformer tingkat token (attention rollout) dan atribusi gradien saliency.

Pilihan Contoh Kalimat Pengujian:
Endpoint Produksi: sensus-ekonomi-sentimen-api.modal.run
Keputusan Klasifikasi: -

Verifikasi Integritas Model Produksi Terpasang
Arsitektur: IndoBERT Base (indobenchmark/indobert-base-p1)
Regularisasi: Konsistensi R-Drop (α=0,5, 124M Parameter)
Data Pengawasan: Label Semu Jev (5.808 Opini) & Partisi Gemma 4 12B IT
Evaluasi Acuan Manusia: Akurasi 0,7882 | Macro F1 0,7700 (100 Baris Gold Set)
Catatan Metodologis: Bobot atensi rollout dan atribusi gradien merepresentasikan korelasi representasi matematis model, bukan pembuktian kausalitas mutlak (Atanasova et al., 2023).

Tahap 1: Google Gemma 4 12B IT Pemilah Relevansi & Konteks

Model LLM sadar konteks di hulu pipeline (judul video & teks induk) untuk memilah 8.352 baris menjadi ember opini (5.808), non-opini (2.119), dan karantina (423).

Tahap 2: TypeSafe AI Jev Anotator Terkalibrasi (15 Sep 2026)

Model diskriminatif non-autoregressive (typed decisions) dengan skema terkunci dan zero hallucination. Melabeli ulang 5.808 opini menjadi data latih sentimen (3.978 neg, 1.315 pos, 515 netral).

Produksi: IndoBERT + R-Drop Akurasi Gold: 0,7882
